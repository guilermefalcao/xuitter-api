# Xuitter API

Clone simples do Twitter desenvolvido com Spring Boot 3.

## Tecnologias

- Java 17
- Spring Boot 3.5.9
- MySQL 8.0
- Docker Compose
- Flyway

## Como executar

1. Subir o banco de dados:
```bash
docker-compose up -d
```

2. Executar a aplicação:
```bash
./mvnw spring-boot:run
```
